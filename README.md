# Тренажёр по корпоративным данным

Мини-приложение для подготовки к экзамену: 20 случайных вопросов в тесте, вопросы из банка не повторяются до конца прохождения.

## Как открыть локально

1. Скачай архив и распакуй его.
2. Открой файл `index.html` двойным кликом.
3. Всё работает без сервера и интернета.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub, например `corporate-data-quiz`.
2. Нажми **Add file → Upload files**.
3. Загрузи файлы из папки: `index.html`, `styles.css`, `app.js`, `questions.js`, `README.md`.
4. Нажми **Commit changes**.
5. Открой **Settings → Pages**.
6. В блоке **Build and deployment** выбери:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
7. Нажми **Save**.
8. Через пару минут GitHub даст ссылку на сайт.

## Что внутри

- `index.html` — страница приложения.
- `styles.css` — красота, карточки и адаптив.
- `app.js` — логика тестов, проверка ответов, прогресс.
- `questions.js` — банк вопросов и ответы.

Прогресс хранится в браузере через `localStorage`. Чтобы начать заново, нажми кнопку «Начать заново» в приложении.

## Важно

Ответы собраны по банку тестовых заданий и логике предмета. В нескольких вопросах формулировки в исходнике неоднозначные; при желании можно вручную поправить ответы в `questions.js`.

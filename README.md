# Корпоративные данные · тренажёр v2

Что добавлено:

- рандомные тесты по 20 вопросов;
- вопросы больше не повторяются в рандомном цикле, пока не закончится банк;
- варианты ответов перемешиваются, поэтому правильные ответы не стоят «кучкой»;
- режим «Марафон» — все задания банка страницами по 20;
- режим «Темы» — можно открыть конкретную тему и решить все задания;
- режим «Ошибки» — копятся вопросы, где последний ответ был неверным;
- кнопка «Пройти заново» сбрасывает текущий режим/тему/марафон;
- локальный профиль по имени;
- экспорт/импорт прогресса для переноса между устройствами.

## Как обновить сайт на GitHub

1. Распакуй архив `corporate-data-quiz-pro.zip`.
2. Открой репозиторий на GitHub.
3. Нажми **Add file → Upload files**.
4. Перетащи все файлы из распакованной папки в корень репозитория:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `questions.js`
   - `README.md`
5. Внизу нажми **Commit changes**.
6. Подожди 1–3 минуты, пока GitHub Pages обновится.

## Важно про память между устройствами

GitHub Pages — это статический сайт. Он не умеет сам хранить общий прогресс на сервере.
Поэтому профиль сохраняется в браузере конкретного устройства.

Для переноса:

1. На первом устройстве нажми **Экспорт прогресса**.
2. Передай JSON-файл на другое устройство.
3. На втором устройстве нажми **Импорт прогресса**.

Настоящая синхронизация по имени с телефона и компьютера возможна, но для неё нужна база данных: например Firebase или Supabase.
